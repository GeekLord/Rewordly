# Security Policy

## Supported Versions

The following table lists the security support status for Rewordly versions:

| Version | Supported |
| --- | --- |
| Latest 2.x release | Yes |
| Older releases | No |

Security fixes ship in a new release; update to the [latest release](https://github.com/GeekLord/Rewordly/releases/latest).

## Reporting a Vulnerability

Do not report security vulnerabilities in public GitHub issues.

### Procedure to Report a Security Issue

1. Open a private report at [Report a vulnerability](https://github.com/GeekLord/Rewordly/security/advisories/new) (GitHub private vulnerability reporting). Only the maintainer can see it. If that page is not available, contact the developer privately through [shobhit.net](https://shobhit.net).
2. Include the following information in your report:
   - Description of the vulnerability.
   - Steps to reproduce the issue.
   - Operating system and version.
   - Potential impact of the vulnerability.
3. Allow up to 48 hours for the maintainers to acknowledge your report.
4. Coordinate with maintainers before public disclosure.
